# 🏥 Multi-Disease Prediction System

This project is a Machine Learning and Deep Learning based web application that predicts the risk of multiple diseases using patient data and medical images.

---

## 🚀 Features

- Diabetes Prediction (ML)
- Heart Disease Prediction (ML)
- Stroke Prediction (ML)
- Pneumonia Detection from Chest X-ray (CNN - Deep Learning)
- User-friendly web interface using Streamlit

---

## 🧠 Technologies Used

- Python
- Machine Learning (Scikit-learn)
- Deep Learning (TensorFlow / Keras)
- Streamlit (Web App)
- OpenCV & PIL (Image Processing)

---

## 📊 Models Used

| Module | Model |
|-------|------|
| Diabetes | Logistic Regression |
| Heart Disease | Logistic Regression |
| Stroke | Logistic Regression (with class balancing) |
| Pneumonia Detection | Convolutional Neural Network (CNN) |
